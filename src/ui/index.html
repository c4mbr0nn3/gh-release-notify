gh-release-notify

GitHub release watch daemon — email notifications on new stable releases.

Sign in

The admin token from config.toml or the ADMIN_TOKEN environment variable.

Settings

The configuration file is not writable. Saving is disabled.

Polling Optional. A 5-field UTC cron expression (day of week: 1=Sunday–7=Saturday). When set, it overrides the poll interval.
